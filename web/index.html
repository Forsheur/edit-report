edit-report

Compares a supplied video against one Forsheur recording, in your browser. Nothing is uploaded: the files are read by this page and never leave the machine. It reaches no verdict about the supplied file and gives it no score — it describes what corresponds, what does not, and what could not be judged.

1 · the original, from the evidence bundle

Unpack the bundle and run its own verifier first — python3 verify_bundle.py . --extract — then point this at extracted/back.mp4. The short id is the tail of the QR URL; with it, this page can check the two-byte signature burned into every frame against the one this recording should carry.

3 · how hard to look inside the picture

A region is located when it stands out from that frame's own spread by more than this many median-absolute-deviations. There is no threshold in grey levels anywhere in this tool: a heavily recompressed frame raises its own bar, so there is no published constant to tune against. Measured on real material at 720×1280, a 200×200 patch pasted over four seconds peaks around 79; the same recording merely recompressed to 150 kbit/s peaks around 11. Lower finds more and cries wolf more.

What this page does not do. It does not check the cryptographic chain. That check belongs to the bundle's own verify_bundle.py, which this project deliberately never re-implements — one implementation of the thing that must be right, not two, and there is no Python in a browser. Run it yourself and read its verdict next to this report. The report says as much where the chain would go.
